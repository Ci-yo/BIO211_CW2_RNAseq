# Project context

This project began as four equally weighted coursework tasks based on the RNA-seq data used in the practical classes. The brief is paraphrased here to preserve the origin and scope of the analysis without making the repository homepage read like an answer sheet.

## Task 1 - Quality control and alignment

Describe the dataset, including the species, sequencing technology, research question and its importance. Assess read quality, trim where necessary, align the reads to an appropriate reference genome, and report data-quality and alignment statistics.

## Task 2 - Reference-guided transcript reconstruction

Choose one BAM file and reconstruct transcripts with StringTie. Compare the reconstructed models with known annotations in IGV and present examples of:

1. an assembly matching the annotation;
2. an assembly differing from the annotation; and
3. a candidate novel transcript.

## Task 3 - Differential expression and functional enrichment

Use featureCounts and/or DESeq2 to perform differential expression analysis. Report the numbers of up- and down-regulated genes at a significance level of 0.05, compare representative loci with TDF coverage in IGV, and interpret GO enrichment of the differentially expressed genes.

## Task 4 - Short essay

Explain what RNA-seq is and how it can be used to study gene regulation. Cover the main experimental and computational steps, information that can be extracted, common problems, future challenges and promising directions.
